# AI 门店运营助手（E 方案）

面向门店、零售和连锁运营的微信小程序核心框架，聚焦客流预测、排班建议和补货建议。当前版本只使用模拟数据，不依赖后端、云环境或第三方 npm 包。

## 当前能力

- 经营总览：展示客流、排班、库存和风险指标。
- 需求预测：在明天、未来 3 天和未来 7 天之间切换，查看预测结果。
- 预测数据导入：支持 CSV、JSON 粘贴和微信文件导入，提供完整性、异常值与样本范围检查。
- 可解释预测：展示趋势、星期因子、回测结果、置信区间、预测原因和动作建议。
- 客流来源与情景分析：提供环形图、增强柱图、促销倍率模拟和自有模型 API 配置。
- 智能排班：展示班次建议、岗位覆盖和风险提示。
- 补货建议：展示建议补货量、原因和处理状态。
- 数据服务层：页面统一通过 `services/operations.js` 获取数据，后续可以替换为云函数或企业 API。

## 运行方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录。
4. AppID 选择“测试号”，或使用项目内的 `touristappid`。
5. 点击“编译”，即可进入四个底部页签。

项目不依赖 npm 构建，也无需开通云开发即可运行。

预测页的数据格式、本地模型和自定义 API 配置见 [预测页使用说明](docs/forecast-guide.md)。

## 后续扩展顺序

1. 接入微信云开发，新增门店、客流、销售、库存和排班数据集合。
2. 将 `services/operations.js` 中的模拟实现替换为云函数调用。
3. 接入预测服务，先使用简单移动平均或指数平滑，再接入模型。
4. 增加角色权限、任务状态、审批和消息订阅。
5. 最后接入 AI 解释与决策建议，避免把密钥放入小程序前端。

## 边界

当前版本是比赛原型骨架，不包含真实企业数据、真实预测模型、账号体系、支付、ERP/POS 集成和生产环境安全配置。
