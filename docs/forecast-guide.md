# 预测页使用说明

## 数据导入格式

预测页支持粘贴 CSV、JSON，也支持从微信聊天文件中选择 `.csv`、`.json` 和 `.txt` 文件。

CSV 表头：

```csv
date,traffic,sales,staff,stock,members,miniProgram,referral,promo,weather
2026-09-01,742,48600,7,168,176,118,62,0,晴
```

字段说明：

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `date` | 否 | 营业日期，推荐使用 `YYYY-MM-DD` |
| `traffic` | 是 | 客流量 |
| `sales` | 是 | 销售额 |
| `staff` | 否 | 在岗人数 |
| `stock` | 否 | 库存量 |
| `members` | 否 | 会员客流 |
| `miniProgram` | 否 | 小程序来源客流 |
| `referral` | 否 | 转介绍来源客流 |
| `promo` | 否 | 是否促销，支持 0/1、是/否 |
| `weather` | 否 | 天气说明 |

中文表头也可识别，例如“日期、客流、销售额、会员、小程序客流、转介绍、促销”。

## 本地免费模型

默认模型完全在小程序前端运行，不依赖后端或密钥，主要由以下部分组成：

- 加权移动平均：增强近期数据权重。
- 线性趋势：识别样本期内的增长或下降方向。
- 最近值修正：降低趋势模型对大波动的过度反应。
- 星期因子：识别工作日与周末的周期性差异。
- 置信区间：根据回测误差、波动率和预测跨度计算。
- 情景倍率：模拟促销、活动或短期经营变化。

模型会把最近值法、3 日移动平均和线性趋势进行回测，并使用 MAPE 展示误差对比。

### 可切换算法

- 集成统计模型：加权移动平均、线性趋势和最近值按权重组合。
- 指数平滑：使用 α=0.35 的指数平滑，对近期变化更敏感。
- 周周期 Holt-Winters：用 7 日周期处理工作日和周末差异。

模型对比表会显示最近值法、3 日移动平均、线性趋势、指数平滑和 Holt-Winters 的 MAPE，数值越小代表回测误差越低。

### 外部和门店因素

- 天气：晴、多云、阴、小雨、中雨、大雨、高温、雪会使用不同经验系数。
- 节假日、促销和本地活动：可在预测页直接切换是否计入。
- 地理位置：从门店地图页选择门店或当前位置，读取周边 500 米/1 公里店铺数量。
- 周边竞争：根据同类门店、店铺密度、平均客流和评分计算竞争指数与位置因子。

首日预测拆解会用细线表格列出统计基础值、天气、节假日、促销、本地活动和位置竞争，避免只看到最终数字。

## 自定义模型 API

“分析与模型设置”内可以填写兼容 OpenAI Chat Completions 的接口地址、模型名称和 API Key。调用结构为：

```json
{
  "model": "model-name",
  "temperature": 0.2,
  "messages": [
    { "role": "system", "content": "你是门店经营分析师。" },
    { "role": "user", "content": "预测摘要与影响因素" }
  ]
}
```

小程序会识别以下常见返回字段：

- `choices[0].message.content`
- `choices[0].text`
- `result`
- `analysis`
- `message`

API Key 只保存在当前页面运行内存中，不写入 Git；接口地址和模型名称可在本机缓存。生产环境建议把第三方模型调用迁移到微信云函数，避免在小程序前端长期保存密钥。

## 门店地图与周边数据

门店地图页支持定位、地图选点、内置门店样本和手工周边参数。可选填写腾讯地图 WebService Key 搜索周边店铺；Key 只保留在当前运行内存，不写入本机缓存或 Git。

如启用腾讯地图接口，需要在微信公众平台把 `apis.map.qq.com` 加入 request 合法域名。未配置 Key 时，手工店铺数量、平均客流和类别同样会生成位置因子。


## 当前限制
- 自定义接口需要加入微信公众平台的 request 合法域名，或在开发工具中关闭域名校验。

- 预测结果、导入数据快照、门店上下文和误差记录保存在小程序本机缓存中，不会自动上传云端。
- 导入包含预测目标日期的实际客流后，误差追踪会自动回填上一轮预测的绝对误差和误差率。
- 腾讯地图周边搜索需要单独申请 WebService Key，并配置合法域名。
- 导入或预测后的数据会保存在本机；恢复样例会覆盖本机数据快照。
- 当前模型适合短周期、单门店经营预测，不适合直接替代财务、库存或供应链系统。
